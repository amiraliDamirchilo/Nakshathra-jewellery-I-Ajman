# Nakshathra Jewellery Ajman (website concept)

7 static pages, English + Arabic (RTL) with a language switch.

- index.html: Home (constellation hero, categories, featured pieces, reviews, store)
- collections.html: Filterable catalogue, each piece has a ref (NK-xx) and an "Ask price & weight" WhatsApp button
- diamonds.html: Diamond pieces + gift shortlist CTA
- wedding-gold.html: Traditional / bridal gold + wedding visit CTA
- reviews.html: Google reviews (4.9 from 3,700)
- store.html: Address, hours, map, store photos
- enquire.html: Enquiry form that opens WhatsApp (+971 52 716 6916)

Deploy: upload the whole folder to any static host. Arabic link: add `?lang=ar`.
Deep links: collections.html?cat=light (light, necklace, chain, earrings, bracelet, ring, diamond, wedding).
